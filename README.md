\# DevOps Student Management System



The DevOps Student Management System (DSMS) is a Java Spring Boot application developed to demonstrate a complete software development and DevOps lifecycle.



\## Project Overview



The system provides core student and academic management functions while applying modern DevOps practices from development through production deployment.



\## Technology Stack



\### Application

\- Java

\- Spring Boot

\- Spring Data JPA

\- Spring Security

\- MySQL

\- Maven



\### Testing

\- JUnit

\- Mockito



\### DevOps

\- Git

\- GitHub

\- GitHub Actions

\- Docker

\- Docker Compose

\- Nginx

\- Terraform



\### Monitoring

\- Spring Boot Actuator

\- Prometheus

\- Grafana



\## Core Features



\- User authentication and authorization

\- User management

\- Department management

\- Program management

\- Student management

\- Course management

\- Enrollment management

\- Search, filtering, sorting, and pagination

\- REST API

\- OpenAPI/Swagger documentation

\- Application health monitoring



\## DevOps Lifecycle



Requirements

→ Development

→ Git Feature Branch

→ Pull Request

→ Automated Testing

→ Continuous Integration

→ Docker

→ Continuous Deployment

→ Infrastructure as Code

→ Monitoring and Logging

→ Production Deployment
